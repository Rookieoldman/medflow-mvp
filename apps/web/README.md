# Medflow — aplicación web (`apps/web`)

Cliente Next.js del monorepo **Medflow MVP**. La documentación principal está en la [**raíz del repositorio**](../../README.md).

## Comandos rápidos

```bash
npm install
npm run dev          # http://localhost:3000
npm run build && npm start
npm test             # Vitest
npx prisma migrate dev
```

Variables de entorno: coloca `.env` o `.env.local` aquí (`DATABASE_URL`, `NEXTAUTH_*`, opcionalmente VAPID). Ver README raíz.
